# Semantic HTML Layout

This project demonstrates a simple web page layout using **semantic HTML5 elements** without any `<div>` tags. It uses **CSS Grid** to structure the page similar to a typical website layout with a header, navigation, sidebars, main content, and footer.

---

## Features

- Fully semantic HTML5: `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`
- CSS Grid for layout structure
- Responsive-friendly with flexible grid columns
- No `<div>` tags used

---


---

## How to Run

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Observe the semantic layout with sidebars and main content.

---

## Example HTML

```html
<header>Header</header>
<nav>Navigation Menu</nav>
<aside id="left">Content</aside>
<main>Main Content</main>
<aside id="right">Content</aside>
<footer>Footer</footer>
